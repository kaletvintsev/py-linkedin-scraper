# Инструкции для агентов

## Контекст проекта

Этот репозиторий — форк библиотеки `linkedin-jobs-scraper`. Форк будет развиваться в более универсальный инструмент для сбора публично доступных данных LinkedIn.

Основные направления развития:

- парсинг публикаций (постов);
- парсинг профилей пользователей;
- сохранение и развитие существующего парсинга вакансий.

При проектировании изменений не следует ограничивать архитектуру только вакансиями. Общие механизмы браузерной сессии, авторизации, навигации, ограничения частоты запросов, обработки ошибок и представления результатов нужно по возможности делать переиспользуемыми для вакансий, постов и профилей.

Новые возможности должны сохранять обратную совместимость существующего API и CLI, если в задаче явно не указано иное. Для новой логики следует добавлять тесты и не выполнять реальные запросы к LinkedIn в автоматических тестах.
